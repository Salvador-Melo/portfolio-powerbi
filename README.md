# 📊 Portfólio Power BI

Este repositório reúne projetos de Business Intelligence desenvolvidos com foco em **educação**, **saúde pública** e **gestão governamental**, a partir de dados reais ou simulados.

Os dashboards aqui apresentados foram construídos com **Power BI**, integrando **DAX**, **Power Query**, **modelagem tabular** e **Row-Level Security (RLS)**.
